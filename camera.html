Enhanced Camera System

Data-driven camera management for UE5. Layer camera behaviors, blends, and shakes using an intuitive stack-based architecture.

Key Features

  • Stack Architecture: Apply modifiers like "Shake", "Lag", or "FOV Zoom" as layers that can be pushed/popped.
  • Data Asset Driven: Define camera profiles in editor and swap them at runtime with one line of code.
  • Sequencer Ready: Seamlessly blend between gameplay cameras and cinematic sequences.

Installation
