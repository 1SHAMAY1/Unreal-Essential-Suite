Enhanced Camera System

Modular, runtime-switchable camera architecture decoupling view logic from character pawns. Features a prioritized push/pop camera stack, anti-jitter smoothing, and seamless Gameplay Ability System (GAS) tag activation.

01 / ARCHITECTURE HIGHLIGHTS
  • Prioritized Push/Pop Stack: Easily push ADS, Sprint, and Cutscene cameras via PushCameraMode with deterministic transition blends.
  • Anti-Snapping Occlusion Handling: Uses LastCollisionLocation caching to prevent jarring camera cuts when geometry clips.
  • Frame-Rate Independent Smoothing: Positional and rotational lag algorithms guarantee smooth tracking across 30, 60, and 120+ FPS.
  • Zero Actor Tick Loops: Directly overrides UpdateCamera on APlayerCameraManager for $O(1)$ evaluation.
02 / INTEGRATION CODE

Set Player Camera Manager Class to AEnhancedPlayerCameraManager:

// Push state in C++:
CamMgr->PushCameraMode(ADSConfig, Tag);
