Character Locomotion System

A production-ready, network-replicated movement component derived from UCharacterMovementComponent. Supports automated 3-point trace vaulting, mantle, sliding, and high climbing with root motion prediction.

Core Architectural Features

  • Full Network Prediction: Every locomotion state transition is predicted on client and authoritative on server.
  • Motion Warping Integration: Seamlessly syncs with Epic's Motion Warping plugin for clean, procedural alignment during mantles and vaults.
  • Data-Asset Driven: Traversal speeds, obstacle trace heights, and collision adjustments configured in modular Data Assets.
  • Pre-Compiled Binaries: Tracked Win64 binaries for UE 5.3, 5.4, and 5.5 ready to run without compiling C++.

Installation

Clone the repository and copy your engine version folder into your project's Plugins/ folder:

git clone https://github.com/1SHAMAY1/Plugin-CharacterLocomotionSystem.git
