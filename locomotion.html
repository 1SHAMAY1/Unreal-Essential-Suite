Character Locomotion System

A production-ready, network-replicated movement component for UE5. Supports climbing, mantle, sliding, and prone states without the bloat of other marketplace assets.

Key Features

  • Full Replication: Every state transition is predicted on client and validated on server.
  • Motion Warping: Integrates seamlessly with UE5 Motion Warping for perfect alignment on vaults.
  • Native Inheritance: Derived from standard `UCharacterMovementComponent` for maximum compatibility.

Installation

git clone https://github.com/1SHAMAY1/Plugin-CharacterLocomotionSystem.git Plugins/Locomotion
